Class 5: the complete site

This is the whole events website, with every image and icon inside the folder. It works offline. Use it if you want to work on your own computer instead of StackBlitz. Working locally is allowed, but it is not supported in class.

What is in here

  • events.html, styles.css, events.js: the Events page, with all five Parts of the lab complete.
  • index.html and app.js: the signed-out Discover page. Sign In opens the Events page.
  • assets/: the images and icons. The pages point at them with relative paths.

How to run it

  1. Unzip the folder.
  2. Double-click events.html to open it in your browser. Or, in a terminal inside the folder, run python3 -m http.server and open http://localhost:8000/events.html.
  3. Edit the files in any editor. Refresh the browser to see your change.

Good to know

  • This copy has the lab finished. If you are still working through Parts 1 to 3, use the lab zip instead.
  • In StackBlitz the class project loads its images from GitHub. Here they are local, so the image paths look different. The JavaScript is the same.
